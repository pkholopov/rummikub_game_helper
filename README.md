# Румикуб — Подсчет очков

Веб-приложение для учёта очков в настольной игре **Румикуб** (Rummikub). Играет на любом устройстве прямо в браузере, без сервера и внешних зависимостей — все данные хранятся в `localStorage`.

## Суть проекта

Румикуб — настольная игра, в которой игроки выкладывают фишки с числами (4 цвета, номера 1–13) в ряды и группы. Раунд заканчивается, когда один из игроков первым избавляется от всех своих фишек (выходит).

По правилам подсчёта:

- проигравшие получают **минус** сумму очков фишек, оставшихся у них на руках;
- победитель получает **плюс** сумму очков всех проигравших;
- **джокер** приравнивается к **30 очкам**.

Приложение автоматизирует весь этот процесс: игроки просто отмечают, какие фишки остались у каждого, и приложение само считает очки и ведёт таблицу результатов по раундам.

## Возможности

- Настройка игры: количество игроков (2–4), имена, случайный выбор первого ходящего, **время на один ход** в секундах.
- Игровой процесс:
  - таймер хода с звуковыми сигналами (середина таймера, последние 10 секунд, финал);
  - **подтверждение начала хода** кнопкой «▶ Начать ход игрока» — ход следующего игрока не начинается автоматически, пока он не готов;
  - передача хода по кругу, автопередача после истечения времени.
- Подсчёт очков:
  - выбор победителя кликом по имени;
  - для каждого проигравшего — **интерактивный выбор оставшихся фишек в модальном окне** (4 цвета × номера 1–13, джокеры), очки считаются автоматически;
  - кнопка **«↩ Отменить»** для отката ошибочного ввода фишек;
  - **блокировка сохранения раунда**, пока кто-то из проигравших не подтвердил свои фишки.
- Таблица результатов: очки по раундам (зелёный «+» / красный «−») и общий итог.
- Кастомные всплывающие уведомления вместо браузерных `alert()`.
- Сохранение состояния игры в `localStorage` (переживает перезагрузку страницы), полный сброс игры.

## Структура проекта

```
Rummikub/
├── index.html   — представление: разметка экранов, модального окна и уведомлений
├── styles.css   — стили всего приложения
├── app.js       — вся логика: таймер, подсчёт очков, модалка фишек, таблица итогов
└── README.md    — описание проекта
```

Код разделён по принципу **«представление / стили / логика»**:

- `index.html` подключает стили через `<link rel="stylesheet" href="styles.css">` и логику через `<script src="app.js">`;
- в HTML не осталось ни встроенных `<style>`, ни `<script>`-блоков.

## Запуск

Откройте `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari). Никаких установок и сборки не требуется.

```
# просто открыть в браузере
xdg-open index.html
```

## Правила подсчёта (как реализовано)

1. Игрок, выбравший все свои фишки первым и нажавший «Завершить раунд», отмечается как **победитель** — у него 0 очков.
2. Каждый проигравший отмечает оставшиеся фишки: номер фишки = её очки, джокер = 30.
3. При сохранении раунда проигравшим начисляется `−сумма фишек`, победителю — `+сумма фишек всех проигравших`.
4. Таблица итогов показывает динамику по раундам и общий баланс каждого игрока (побеждает тот, у кого больше очков).
